  ✓ BLACKOUT ELEITORAL — zero anúncios até 05/10/2026
  ✓ CÓDIGO 100% ABERTO — auditável no GitHub
  ✓ STACK R$ 0/mês — independência financeira total

Seu teste hoje protege a experiência de milhares de eleitores
que usarão a ferramenta no dia 04/10/2026.

Cada bug que você encontrar é um eleitor que não será enganado.
Cada sugestão que você enviar é uma camada a mais de transparência.
