# Nota de Transparência — Lançamento Eleições Progressistas v2.2.0

**Data:** 10 de setembro de 2026
**Versão:** 2.2.0 (Beta Fechado)

## 🇧🇷 O que é
Plataforma cívica gratuita que conecta eleitores a candidatos progressistas
auditáveis via TSE. Sem cadastro. Sem coleta de opiniões. Sem anúncios invasivos.

## 🛡️ Nossos compromissos
- **Coleta Zero:** nenhum dado político é armazenado
- **Transparência Radical:** código-fonte 100% aberto
- **Blackout Eleitoral:** anúncios desativados até 05/10/2026
- **Privacidade por Design:** matching stateless (memória de sessão)
- **Memória de Cálculo Auditável:** Raio-X com pesos 40/30/30 públicos

## 📊 Stack técnico (R$ 0-150/mês)
- API: Render free tier
- Frontend: Cloudflare Pages
- Banco: Supabase (sa-east-1)
- Monitoramento: Sentry
- Mobile: Expo + React Native
